STOICH web demo

Same Python files as the calculator (src/*.py), running in the browser with Pyodide. ti_draw is redrawn on a canvas.

Typing on your PC

N aletters: type NaCl normally. A lowercase letter picks the 2-letter symbol from the list
0–9 ( ) .numbers. The page presses [x,t,θ,n] for you to switch ABC→123
*[×]: hydrate dot / ×10^
-[−] (negative exponent)
, / Spacelazy mode: next element
Tab[x,t,θ,n]
Enter Bksp Escenter / del / clear
Arrowsarrow pad (pick list, scroll the work)
F1–F5top row (bottom-bar labels)

On the keypad: letter fields read each key as its green letter (A-lock is always on), so there's no need to press [alpha].

Differs from the real Evo

  • Key codes are the CE Python wait_key() codes. TI doesn't publish the Evo's codes, so run KEYTEST on the calc to confirm them.
  • Font: the demo uses a fixed 10×16 px cell. The calc's ti_draw font may be narrower or proportional, which shifts the spacing a little.
  • Speed: redraws here are instant. A full-screen redraw on the calc may flicker.
  • Glyphs: × and · may not exist in the calc font. If they look wrong, change one line in stoich_ui.py.
  • PC keyboard shortcuts (auto ABC/123 switching, lowercase picks) exist only in the demo. On the calc you press [x,t,θ,n] and use the pick list.
  • [2nd]/[alpha]/A-lock are emulated by this page, the way the OS does it.
